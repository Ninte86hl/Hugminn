# Reporting bugs

Open Hugminn's settings → **Report a bug** → *Report bug on GitHub*. Your browser opens a new [issue](https://github.com/Ninte86hl/Hugminn/issues) already filled in with the version, your device and the last error. Describe briefly what happened and submit it (you need a GitHub account).

Hugminn itself never sends anything.

Helpful to include:
- What you did right before the problem
- Which emulator or app was running
- A screenshot (Select button in the switcher or the Control Center)
