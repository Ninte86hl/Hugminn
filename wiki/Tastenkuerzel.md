# Tastenkürzel und angeheftete Apps

## Tastenkürzel-Hilfe im Switcher
Im [Game Switcher](Game-Switcher-DE) einen Emulator (oder RetroArch) auswählen und **Y → Tastenkürzel** drücken: Eine Karte zeigt die wichtigsten Kürzel mit deinen Tastensymbolen – Emulator-Menü, Spiel beenden, Spielstand speichern und laden, Speicherplatz wechseln, Vorspulen, Zurückspulen und Pause. B schließt sie.

Hugminn ändert nichts am Emulator; es zeigt, was du eingerichtet hast. Standard ist die **gängige Belegung** mit Select als Hotkey, wie bei EmuDeck, ROCKNIX, Batocera oder RetroPie:

| Aktion | Tasten |
| --- | --- |
| Emulator-Menü | L3 + R3 |
| Spiel beenden | Select + Start |
| Spielstand speichern / laden | Select + R1 / Select + L1 |
| Speicherplatz wechseln | Select + ◀ / ▶ |
| Vorspulen / Zurückspulen | Select + R2 / Select + L2 |
| Pause | Select + A |

## Eigene Belegung
Einstellungen → **Tastenkürzel**: Emulator mit **L1 / R1** wählen, *Belegung* auf *Gängig*, *Eigene* oder *Aus*. Eine Aktion antippen und **die Tasten gleichzeitig halten, dann loslassen** – diese Kombination wird übernommen. *Nicht belegt* löscht sie.

## Angeheftete Apps
**Y → Anheften** im Switcher hält eine App offen: X schließt sie nicht mehr, und *Alle anderen schließen* lässt sie in Ruhe – praktisch für Musik oder einen Stream im Hintergrund. Eine angeheftete App zeigt eine kleine Pinnadel direkt neben ihrem Namen. **Y → Lösen** hebt das auf.
