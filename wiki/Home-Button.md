# Home button

Hugminn listens to the Home button; the Back button is left alone so it keeps working in RetroArch and other emulators.

| Button | Default action |
| --- | --- |
| Home (press) | Home, as usual |
| Home (double press) | [Game Switcher](Game-Switcher) |
| Home (hold) | [Control Center](Control-Center) |

**External controllers** (e.g. an 8BitDo over Bluetooth or USB): their Home/Guide button works the same way. You can turn this off in the [settings](Settings) → *Home button* → *Home button on a controller*, for example if an emulator uses the Guide button itself. More in [External controller](External-Controller).

Without any button: see [Shortcuts](Shortcuts).

Every gesture can be reassigned in the [settings](Settings) → *Home button*: home, game switcher, Control Center, Android's recent apps, the last app, or a [capture](Capture) action (screenshot, record video / stop, save the last seconds). The time for a double press and for a long press can be adjusted too; a shorter double-press time makes a single press react faster.
