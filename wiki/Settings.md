# Settings

Open the Hugminn app (or the gear in the Control Center). The settings are grouped into pages; B goes back to the overview.

## Status
Shows whether Hugminn is switched on as an accessibility service, whether the handheld's root service was found and whether Hugminn is on the background whitelist (so the system does not end it). Buttons fix what is missing.

## Look
| Option | |
| --- | --- |
| Language | System, German or English |
| Style | Modern, Pixel, Dot matrix or Cocoon; applies everywhere: Control Center, switcher, overlay and the settings |
| Tile colour | Colour of active tiles, also the accent colour |
| Colour scheme | System, light, dark, OLED black (true black, saves power on OLED screens) |
| Button symbols | Automatic, Xbox, Nintendo or PlayStation; coloured or plain |

## Home button
Action for a single, double and long press, and the times for double and long presses. See [Home button](Home-Button).

## Game Switcher
| Option | |
| --- | --- |
| Own overview | On: Hugminn's own switcher with its own previews. Off: a frame over Android's recent apps |
| Pause the game | The app behind the switcher is covered and pauses, including sound |
| Swipe gesture | Hugminn also takes over when the recent apps are opened by swiping up |
| Status bar | Clock and battery in the chosen style, nothing, or Android's normal bar |

## Control Center
| Option | |
| --- | --- |
| Rows / Columns | Size of the grid (4 rows by default, 5 on 4:3 screens such as the Pocket Nova); columns *Automatic* fits as many square cells as possible |
| Pause the game | The game pauses while the Control Center is open |
| Status bar | As above, for the Control Center |
| LED app | Who sets the stick LED colours: Hugminn or an installed LED app |
| Gauge colours | Traffic light, cool → warm, accent colour or monochrome |
| Tiles | Which tiles are shown. Layout and order are changed in the Control Center itself ([Editing](Editing-the-Control-Center)) |

## Profiles per app
Every app and game with a remembered performance or fan profile (games as "Title · Emulator"), with a button to remove it. See [Performance and fan](Performance-and-Fan).

## Backup
Save all settings (layout, tiles, colours, profiles …) to a file and restore them later, for example after reinstalling or on a second device.
