# Fehler melden

Öffne Hugminns Einstellungen → **Fehler melden** → *Fehler auf GitHub melden*. Dein Browser öffnet ein neues [Issue](https://github.com/Ninte86hl/Hugminn/issues), schon ausgefüllt mit Version, Gerät und dem letzten Fehler. Beschreib kurz, was passiert ist, und schick es ab (dafür brauchst du ein GitHub-Konto).

Hugminn selbst sendet nie etwas.

Hilfreich sind:
- Was du direkt vor dem Problem gemacht hast
- Welcher Emulator oder welche App lief
- Ein Screenshot (Select-Taste im Switcher oder Control Center)
