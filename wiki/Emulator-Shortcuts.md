# Emulator shortcuts and pinned apps

## Shortcut help in the switcher
In the [Game Switcher](Game-Switcher), select an emulator (or RetroArch) and press **Y → Shortcuts**: a card shows its important shortcuts with your button symbols – emulator menu, quit game, save and load state, change save slot, fast forward, rewind and pause. B closes it.

Hugminn doesn't change anything in the emulator; it shows what you set up. By default it uses the **common layout** with Select as hotkey, as on EmuDeck, ROCKNIX, Batocera or RetroPie:

| Action | Buttons |
| --- | --- |
| Emulator menu | L3 + R3 |
| Quit game | Select + Start |
| Save state / load state | Select + R1 / Select + L1 |
| Change save slot | Select + ◀ / ▶ |
| Fast forward / rewind | Select + R2 / Select + L2 |
| Pause | Select + A |

## Your own layout
Settings → **Emulator shortcuts**: choose the emulator with **L1 / R1**, set *Layout* to *Common*, *Own* or *Off*. Tap an action and **hold the buttons together, then let go** – that combination is taken. *Not set* clears it.

## Pinned apps
**Y → Pin** in the switcher keeps an app open: X no longer closes it and *Close all others* leaves it alone – handy for a music app or a stream in the background. A pinned app shows a small pin right next to its name. **Y → Unpin** undoes it.
