# Einstellungen

Öffne die Hugminn-App (oder das Zahnrad im Control Center). Die Einstellungen sind in Seiten gegliedert; B geht zurück zur Übersicht.

## Status
Zeigt, ob Hugminn als Bedienungshilfe eingeschaltet ist, ob der Root-Dienst des Handhelds gefunden wurde und ob Hugminn auf der Hintergrund-Whitelist steht (damit das System es nicht beendet). Knöpfe beheben, was fehlt.

## Darstellung
| Option | |
| --- | --- |
| Sprache | System, Deutsch oder Englisch |
| Stil | Modern, Pixel, Punktmatrix oder Cocoon; gilt überall: Control Center, Switcher, Overlay und Einstellungen |
| Kachelfarbe | Farbe aktiver Kacheln, zugleich die Akzentfarbe |
| Farbschema | System, hell, dunkel, OLED-Schwarz (echtes Schwarz, spart auf OLED-Bildschirmen Strom) |
| Tastensymbole | Automatisch, Xbox, Nintendo oder PlayStation; farbig oder schlicht |

## Home-Taste
Aktion für einfachen, doppelten und langen Druck sowie die Zeiten für Doppeldruck und langen Druck. Siehe [Home-Taste](Home-Taste).

## Game Switcher
| Option | |
| --- | --- |
| Eigene Übersicht | An: Hugminns eigener Switcher mit eigenen Vorschaubildern. Aus: ein Rahmen über Androids Übersicht |
| Spiel pausieren | Die App hinter dem Switcher wird verdeckt und hält an, auch der Ton |
| Auch bei Wischgeste | Hugminn übernimmt auch, wenn die Übersicht per Wischen von unten geöffnet wird |
| Statusleiste | Uhrzeit und Akku im gewählten Stil, nichts oder Androids normale Leiste |

## Control Center
| Option | |
| --- | --- |
| Zeilen / Spalten | Größe des Rasters; Spalten *Automatisch* nimmt so viele quadratische Felder, wie passen |
| Spiel pausieren | Das Spiel hält an, solange das Control Center offen ist |
| Statusleiste | Wie oben, für das Control Center |
| LED-App | Wer die Farben der Stick-LEDs einstellt: Hugminn oder eine installierte LED-App |
| Farben der Anzeigen | Ampel, kalt → warm, Akzentfarbe oder einfarbig |
| Kacheln | Welche Kacheln angezeigt werden. Anordnung und Reihenfolge änderst du im Control Center selbst ([Bearbeiten](Control-Center-bearbeiten)) |

## Profile pro App
Jede App und jedes Spiel mit gemerktem Leistungs- oder Lüfterprofil (Spiele als „Titel · Emulator“), mit einem Knopf zum Entfernen. Siehe [Leistung und Lüfter](Leistung-und-Luefter).

## Sichern
Alle Einstellungen (Layout, Kacheln, Farben, Profile …) in eine Datei sichern und später wiederherstellen, etwa nach einer Neuinstallation oder auf einem zweiten Gerät.
