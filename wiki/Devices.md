# Devices

*[Deutsche Version](Geraete)*

Hugminn is made for Android handhelds from **Retroid** and **AYN**. It detects the device and only shows what that device supports. This page lists the most important handhelds, which ones are already tested, and what works on them.

**Legend:** ✅ works · ⚠️ works with limits · ❌ does not work · ❔ not tested yet

## Overview

| Device | Status |
| --- | --- |
| Retroid Pocket 6 | ✅ tested – primary device |
| Retroid Pocket Nova | ✅ tested |
| Retroid Pocket 5 | ✅ tested |

| G2 | ❔ a tester has announced a report |
| AYN Odin 2 | ✅ tested |
| AYN Odin 2 Mini / Odin 2 Portal | ❔ not tested yet – should behave like the Odin 2 |

| Retroid Pocket Dual (two screens) | 🕓 planned later, as its own update |

Your handheld is missing or still marked ❔? Run the [device test](Device-Test) and send the report – that is how a device gets onto this list.

### G2 · Odin 2 Mini / Portal
Nothing confirmed yet. Hugminn's basics (game switcher, Control Center, Home button) should work on every Android handheld; device-specific features such as performance and fan profiles, stick LEDs or the button layout depend on the manufacturer's firmware and may need adjustments. A device report shows exactly what is missing.

### Dual-screen devices (AYN Thor, Retroid Pocket Dual)
Planned as their own update – including brightness for both screens and where the overlays appear.

For the **Anbernic RG DS** and **RG DS Plus** (ROCKNIX, not Android) there is already the sister project **[RetroDualStation](https://github.com/Ninte86hl/RetroDualStation)**.
